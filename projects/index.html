Physics-Consistent Arctic Sea Ice Forecast

Type: Research engineering, remote sensing, scientific prediction
Repository: junwangchen1541/physics-consistent-arctic-sea-ice-forecast

A lightweight deep-learning project for seasonal Arctic sea ice concentration prediction with 1–6 month lead times. It explores physical variables, season-aware temporal modeling, and reproducible Jupyter/Python workflows.

ARF-RWKV

Type: Multimodal remote sensing, hyperspectral classification
Repository: junwangchen1541/ARF-RWKV

Asymmetric redundancy-filtered fusion for multisource hyperspectral imagery. The public package covers HSI–LiDAR and HSI–SAR classification, with models, controlled ablations, data interfaces, evaluation tools, and visualization entry points.

Qidu Story System

Type: Interactive fiction, cross-platform engineering
Repository: junwangchen1541/qidu-story-system

A narrative game system with shared JavaScript story data and state transitions for web and WeChat Mini Program renderers. It covers branching dialogue, map exploration, messages, multiple endings, and save migration. The public development version includes a web demonstration with placeholder assets.
